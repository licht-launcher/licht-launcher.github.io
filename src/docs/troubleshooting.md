# Troubleshooting

## Report a problem

[Open an issue](https://github.com/mateusneiva/licht-launcher/issues) with:

- your launcher version and operating system;
- the game and loader version, when relevant;
- what happened and how to reproduce it.

## Sharing logs

Game logs are shown in the launcher. Minecraft and mods can also write their own log and crash files in profile folders. Licht Launcher does not upload logs or crash reports automatically.

Logs can contain player names, local file paths and server addresses. Remove private information from logs and screenshots before sharing them, and never send passwords or tokens.

## Private reports

For security reports, privacy questions or other private enquiries, email [mateus.fneiva@gmail.com](mailto:mateus.fneiva@gmail.com) instead of posting details publicly.

## Local data

Profiles, worlds and saved accounts can remain after uninstalling. See [Privacy Policy: retention and deletion](/privacy#retention-and-deletion).

## Code signing

Windows publisher signing is not yet available, so Windows may warn about an unknown publisher. See the [code signing policy](https://github.com/mateusneiva/licht-launcher/blob/main/docs/contributing/CODE_SIGNING.md).
