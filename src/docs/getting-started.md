# Getting started

## Download

Choose the package for your system on the [latest release page](https://github.com/mateusneiva/licht-launcher/releases/latest), which also has the release notes.

| Your system | Package |
| --- | --- |
| Windows (64-bit) | `.exe` installer |
| Linux (64-bit) | `.AppImage` |
| Debian, Ubuntu and compatible distributions | `.deb` package |

Portable downloads are also available for Windows and Linux.

## First launch

1. Install Licht Launcher for your system.
2. Open Settings and sign in with Microsoft, or choose an offline username.
3. Create a profile and choose a game version or modpack.
4. Let the launcher prepare the game files, then select **Play**.

Microsoft sign-in opens in your browser. Licht Launcher never asks for your Microsoft password. The launcher downloads the Java version your game needs automatically.

## Updates

Check for new launcher versions from Settings, and choose whether to enable automatic checks. Update downloads are verified with the launcher's signing key.

## Uninstall

- **Windows:** close the launcher and remove it through Windows Settings > Apps.
- **Linux `.deb`:** remove the package through your system's package manager.
- **AppImage or portable:** close the launcher and remove the executable and any shortcuts you created.

Uninstalling may leave profiles, worlds and saved accounts on the computer. See [how to remove local data](/privacy#retention-and-deletion).
