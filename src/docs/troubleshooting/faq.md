# FAQ

## Is Licht Launcher free?

Yes. It is free and open source under the [MIT License](https://github.com/licht-launcher/licht-launcher/blob/main/LICENSE).

## Do I need to buy Minecraft?

Yes. Licht Launcher does not include a Minecraft license, so you need the appropriate game rights to play.

## Is it an official launcher?

No. It is an unofficial project, not affiliated with Mojang Studios or Microsoft.

## Which systems does it run on?

64-bit Windows and Linux. macOS is not supported at the moment.

## Why is it called an Early Release?

Features and compatibility are still being refined, and you may find bugs. Reports help shape it. See [Open an issue](/docs/troubleshooting/open-an-issue).

## Does Licht Launcher see my Microsoft password?

No. Sign-in happens in your browser on Microsoft's own pages.

## Do I need to install Java?

No. The launcher downloads the Java runtime each game version needs. See [Create your first profile](/docs/getting-started/first-profile).

## Does it collect analytics or crash reports?

No product analytics and no automatic crash-report uploads. The launcher still contacts services it needs, such as Mojang, Microsoft, mod providers and GitHub. See the [Privacy Policy](/privacy-policy).

## Can I import profiles from another launcher?

Not at the moment. Importing from other launchers is only an idea on the [roadmap](/docs/contributing/roadmap).

## Can I install single mods from the launcher?

Not yet. Use modpacks for now. See [Installed content](/docs/getting-started/first-profile#installed-content).

## How can I support the project?

You can [sponsor the maintainer on GitHub](https://github.com/sponsors/mateusneiva) or contribute. See [Contributing](/docs/contributing/).
