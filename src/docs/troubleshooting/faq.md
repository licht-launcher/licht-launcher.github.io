# FAQ

## Is Licht Launcher free?

Yes. It is free and open source under the [MIT License](https://github.com/mateusneiva/licht-launcher/blob/main/LICENSE).

## Do I need to buy Minecraft?

Yes. Licht Launcher does not include a Minecraft license, so you need the appropriate game rights to play.

## Is it an official launcher?

No. It is an unofficial project, not affiliated with Mojang Studios or Microsoft.

## Which systems does it run on?

64-bit Windows and Linux. macOS is not supported at the moment.

## Why is it called an Early Release?

Features and compatibility are still being refined, and you may find bugs. Reports help shape it. See [Logs and reporting a problem](/docs/troubleshooting/logs-and-reporting).

## Does Licht Launcher see my Microsoft password?

No. Sign-in happens in your browser on Microsoft's own pages. See [Sign in](/docs/getting-started/sign-in).

## Can I play without a Microsoft account?

Yes, with an offline profile. It does not authenticate you with online services. See [Sign in](/docs/getting-started/sign-in#offline-profile).

## Do I need to install Java?

No. The launcher downloads the Java runtime each game version needs. See [Create your first profile](/docs/getting-started/first-profile).

## Does it collect analytics or crash reports?

No product analytics and no automatic crash-report uploads. The launcher still contacts services it needs, such as Mojang, Microsoft, mod providers and GitHub. See the [Privacy Policy](/privacy).

## Can I import profiles from another launcher?

Not at the moment. Importing from other launchers is only an idea on the roadmap.

## Can I install single mods from the launcher?

Not yet. Use [modpacks](/docs/modding/modpacks) for now. See [Managing installed content](/docs/modding/managing-content).

## How can I support the project?

You can [sponsor the maintainer on GitHub](https://github.com/sponsors/mateusneiva) or contribute. See [Contributing](/docs/contributing).
