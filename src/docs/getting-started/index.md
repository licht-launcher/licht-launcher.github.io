# Overview

Licht Launcher is a free, open-source launcher for **Minecraft: Java Edition** on **Windows and Linux** (64-bit). It keeps your game versions, modloaders and modpacks in separate profiles, and prepares the Java runtime each game needs.

::: warning Early Release
Licht Launcher is in active development. Features and compatibility are still being refined, and you may run into bugs. [Reporting a problem](/docs/troubleshooting/open-an-issue) helps shape the launcher.
:::

## What you need

- A 64-bit Windows or Linux computer.
- The appropriate Minecraft: Java Edition rights. Licht Launcher does not include a Minecraft license.
- An internet connection for the first install. The launcher downloads game files from Mojang, and Java and loaders on demand.

You do not need to install Java yourself.

## What it does

- **Separate profiles** keep each game version and modpack in its own folder.
- **Vanilla or modded:** choose Fabric, Quilt, Forge or NeoForge when you create a profile.
- **Modpacks** can be browsed and imported from Modrinth and CurseForge.
- **Accounts:** sign in with Microsoft, or use a local offline profile.
- **Built-in controls** for game settings, installed content and game logs.

## Where to go next

1. [Install](/docs/getting-started/install) the launcher for your system.
2. [Sign in](/docs/getting-started/sign-in) with Microsoft or choose an offline name.
3. [Create your first profile](/docs/getting-started/first-profile) and press **Play**.

For mods, see [Modloaders](/docs/reference/game-runtime#modloaders) for how Fabric, Quilt, Forge and NeoForge are handled.
