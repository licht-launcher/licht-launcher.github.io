# Updates and uninstall

## Updates

Check for new launcher versions from **Settings**. In the updater settings you can:

- turn **Check for updates automatically** on or off. This controls the check at startup.
- turn **Install deferred updates on restart** on or off, which decides whether an update you postponed is installed on the next launch.

Update downloads are verified with the launcher's signing key. You can also download any version from [GitHub Releases](https://github.com/mateusneiva/licht-launcher/releases).

::: info
Turning off automatic update checks does not stop every network request. Manual checks and other features still make their own requests. See the [Privacy Policy](/privacy).
:::

## Uninstall

- **Windows:** close the launcher and remove it through Windows Settings > Apps.
- **Linux `.deb`:** remove the package through your system's package manager.
- **AppImage or portable:** close the launcher and remove the executable and any shortcuts you created.

## Your data after uninstalling

Uninstalling may leave profiles, worlds and saved accounts on the computer. To remove them too, follow [Local data and removal](/docs/troubleshooting/local-data). Back up any worlds you want to keep first.
