# Documentation

Licht Launcher is a free, open-source launcher for Minecraft: Java Edition on Windows and Linux. It is in an **Early Release**, so features and compatibility are still being refined.

- [Getting started](/docs/getting-started): download, install, sign in and play.
- [Profiles and mods](/docs/profiles-and-mods): game versions, mod loaders and modpacks.
- [Troubleshooting](/docs/troubleshooting): reporting problems, logs and local data.
- [Contributing](/docs/contributing): development setup and the contribution workflow.

Licht Launcher does not include a Minecraft license. You need the appropriate game rights to play.
