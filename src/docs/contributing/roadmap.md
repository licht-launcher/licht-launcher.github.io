# Roadmap

This page summarizes the launcher's roadmap. The roadmap in the launcher repository is the source of truth and changes more often than this page, so check [ROADMAP.md](https://github.com/mateusneiva/licht-launcher/blob/main/docs/ROADMAP.md) for the latest status.

## Status by phase

| Phase | Status |
| --- | --- |
| Foundation | Closed |
| Mojang data (parsing) | Done |
| Downloads | Done; resumable engine, persistent jobs and managed installs in review |
| Java | Done |
| Game assembly and execution | Done; first milestone reached on Windows |
| Basic interface | Closed |
| Instances | Closed |
| Microsoft login | Done; second milestone reached |
| Modloaders | Done |
| Mods and modpacks | In progress; installing individual mods is pending |
| Polish and distribution | In progress |

## Open items

- **Downloads:** manual validation on Windows and Linux of the resumable engine, persistent jobs and managed installs. A dedicated download-history page is planned.
- **Linux launch:** not re-checked in the latest compatibility pass.
- **Mods:** install, update and dependency resolution for individual mods. Listing, enabling, disabling and removing content already exist. See [Managing installed content](/docs/modding/managing-content).
- **Installers:** MSI and Flatpak, as additional distribution formats. Windows installer and portable, Linux AppImage and `.deb`, and portable builds are already generated by CI.
- **Performance review:** startup time, idle memory and download throughput.
- **Public v1.0:** the next major milestone.

## What is already in place

- Modrinth modpack search and `.mrpack` import, and CurseForge import with an API key. See [Modpacks](/docs/modding/modpacks).
- Automatic updates with signed packages. See [Releasing](/docs/contributing/releasing).
- No product analytics and no automatic crash-report uploads.

## Ideas for later

These are outside the current scope:

- World backup and restore
- Importing instances from other launchers (Prism, MultiMC)
- Skins and cape management
- macOS support
- Plugins and themes
- Favorite servers with a status ping

## Helping out

Pick an open item, or propose your own, in an [issue](https://github.com/mateusneiva/licht-launcher/issues). For items marked as needing approval, agree on a plan with the maintainer first. See the [contributing overview](/docs/contributing/).
