# Roadmap

**9 of 11 phases are complete.** The other two, mods and modpacks and polish and distribution, are active. The next major milestone is a public **v1.0**.

This page summarizes the launcher's roadmap. The roadmap in the launcher repository is the source of truth and changes more often than this page, so check [ROADMAP.md](https://github.com/mateusneiva/licht-launcher/blob/main/docs/ROADMAP.md) for the latest status.

## Open items

<div class="roadmap-table">

| Area | Status | Item |
| --- | --- | --- |
| Mods | <Badge type="warning" text="Pending" /> | Install, update and resolve dependencies for individual mods. Listing, enabling, disabling and removing content already exist. See [Installed content](/docs/getting-started/first-profile#installed-content). |
| Installers | <Badge type="warning" text="Pending" /> | MSI and Flatpak as additional formats. Windows installer and portable, Linux AppImage and `.deb`, and portable builds are already generated by CI. |
| Performance | <Badge type="warning" text="Pending" /> | Review of startup time, idle memory and download throughput. |
| Downloads | <Badge type="info" text="In review" /> | Manual validation on Windows and Linux of the resumable engine, persistent jobs and managed installs. A download-history page is planned. |
| Linux | <Badge type="danger" text="Unverified" /> | Launch was not re-checked in the latest compatibility pass. |
| Release | <Badge type="info" text="Milestone" /> | Public v1.0. |

</div>

## Already in place

- <Badge type="tip" text="Done" /> Modrinth modpack search and `.mrpack` import, and CurseForge import with an API key.
- <Badge type="tip" text="Done" /> Automatic updates with signed packages. See [Releasing](/docs/contributing/releasing).
- <Badge type="tip" text="Done" /> No product analytics and no automatic crash-report uploads.

## Helping out

Pick an open item, or propose your own, in an [issue](https://github.com/mateusneiva/licht-launcher/issues). For items marked as needing approval, agree on a plan with the maintainer first. See [How to contribute](/docs/contributing/).
