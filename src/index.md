## Before you play

Licht Launcher is an **unofficial project, not affiliated with Mojang Studios or
Microsoft**. You need the appropriate Minecraft game rights; the launcher's MIT
license does not include a Minecraft license.

Read the [Privacy Policy](./privacy.md) and [Terms of Use](./terms.md) for details
about authentication, local storage, network requests, and third-party services.

## Downloads and code signing

Get installers and portable builds from the
[official GitHub Releases page](https://github.com/mateusneiva/licht-launcher/releases/latest).
See the [code signing policy](https://github.com/mateusneiva/licht-launcher#code-signing-policy)
for the current signing status and release responsibilities.
